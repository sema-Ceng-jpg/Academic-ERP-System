# Academic ERP System

## Overview

Academic ERP System is a Java-based project that simulates the core functionalities of an academic management system. It was developed to practice Object-Oriented Programming (OOP) principles and strengthen Java programming skills.

## Features

- Student management
- Instructor management
- Academic management operations
- Object-Oriented Programming (OOP) architecture
- Class inheritance and encapsulation

## Technologies

- Java
- Git
- GitHub
- Object-Oriented Programming (OOP)
